# Capri.exe: установщик, мастер настройки, скины

## Для обычного пользователя

1. Скачай `CapriSetup-<версия>.exe` из [Releases](https://github.com/idemenkov93/capri/releases).
2. Запусти его. Права администратора не нужны: Капри ставится в папку пользователя.
   Windows может показать «Windows защитила ваш компьютер», потому что у программы нет платной подписи.
   Тогда нажми **«Подробнее» → «Выполнить в любом случае»**.
3. При первом запуске откроется **мастер настройки**:
   - он определяет процессор, память и видеокарту;
   - предлагает модель: **быстрая / средняя / умная** (★ — та, что подходит твоему железу);
   - сам ставит Ollama, модель, голос и, если хочешь, Claude Code (для Claude нужна подписка Pro/Max).

Мастер можно запустить снова через меню Капри → «⚙ Мастер настройки» или ярлык «Мастер настройки Капри» в «Пуске».

Где что лежит:

| Что | Где |
|---|---|
| Программа | `%LOCALAPPDATA%\Programs\Capri` |
| Настройки, журнал, модели голоса | `%LOCALAPPDATA%\Capri` (`config.yaml`, `data\`) |
| Свои анимации | `%LOCALAPPDATA%\Capri\assets\custom` |
| Скины | `%LOCALAPPDATA%\Capri\skins` |

При удалении и обновлении программы настройки и анимации не трогаются.

## Какая модель под какое железо

Для модели важна **память видеокарты**, а не её серия.

| Видеопамять | Быстрая | Средняя | Умная |
|---|---|---|---|
| нет видеокарты / до 7 ГБ | qwen3:1.7b | qwen3:4b | qwen3:8b |
| 7–19 ГБ | qwen3:4b | qwen3:8b | qwen3:14b |
| 20 ГБ и больше | qwen3:8b | qwen3:14b | qwen3:30b |

Музыка, окна, громкость, ссылки и другие команды от модели не зависят.

## Скины (внешность)

Скин — это папка в `skins\` с GIF/PNG/WEBP. Название скина = имя папки:

```
skins\
  моя-капри\
    desktop\   ← на рабочем столе (лучше GIF с прозрачным фоном)
    hud\       ← экран в окне «Personal Link»
  другая\
    idle.gif  walk.gif  dance1.gif …   ← можно без desktop/hud
```

Тип анимации определяется по слову в имени файла: `idle`, `walk`, `sit`, `think`, `talk`, `listen`, `teleport`, `dance`.
Несколько файлов одного типа Капри чередует.
Выбрать скин: меню → «🎭 Внешность». После выбора Капри перезапустится.

## Личная сборка (с твоими анимациями)

Публичная сборка на GitHub — без картинок персонажа, их нельзя распространять.
Свою полную версию собирай у себя:

```
cd E:\Project\Capri
.\build_exe.bat
```

Скрипт берёт `assets\custom`, собирает `dist\Capri\Capri.exe`, проверяет сборку и делает
`dist\CapriSetup-<версия>-personal.exe`. Inno Setup он поставит сам через winget.
**Только для себя:** эту сборку никуда не выкладывай.

## Как выпустить новую версию

1. Подними `__version__` в `capri/__init__.py`.
2. `git tag v0.9.1 && git push origin v0.9.1`.
3. GitHub Actions соберёт установщик и выложит его в Releases. Капри у пользователей увидит обновление в меню «⬆ Проверить обновления».
