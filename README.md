# CAPRI — локальный ИИ-компаньон для рабочего стола

Фан-проект, вдохновлённый Капри из *Cyberpunk: Edgerunners 2*. Живёт на рабочем столе, понимает русский, немецкий, английский (и иврит),
запускает программы, ищет информацию, ставит таймеры — а сложные задачи передаёт **Claude**.

> Неофициальный фан-проект. Не связан с CD PROJEKT RED, Studio Trigger или Netflix.
> Арт из сериала в репозиторий не входит — по умолчанию используется оригинальный аватар.

![hud](docs/hud.png)

## Как это работает

```
 запрос ──► быстрые правила ──► действие (мгновенно, без ИИ)
              │ не узнал
              ▼
          локальная модель (Ollama) ──► ответ / инструмент
              │ сложная задача
              ▼
          Claude Code (claude -p, по твоей подписке)
```

| Пример запроса | Кто обрабатывает |
|---|---|
| «открой браузер», «таймер на 10 минут», «загугли настройка VLAN» | правила ⚡ |
| «что такое DHCP?», «найди инфу по DNS» | Ollama ◆ |
| «напиши PowerShell-скрипт бэкапа», «/claude разбери ошибку…» | Claude ✦ |

## Безопасность

- Программы запускаются **только из белого списка** в `config.yaml` — никакого произвольного shell.
- Сайты — только `http/https`.
- Перед запуском программ и сайтов — **окно подтверждения** (`confirm_actions`).
- Claude Code работает в режиме `plan`: только читает и отвечает, файлы не меняет.
- Локальная модель работает на твоём ПК, данные никуда не уходят. Наружу уходит только то, что ты сам отправил Claude.

## Установка (Windows)

1. **Python 3.11+** — https://www.python.org (галочка «Add to PATH»).
2. **Ollama** — https://ollama.com, затем в терминале:
   ```
   ollama pull qwen3:8b
   ```
   **Какую модель выбрать:**

   | Компьютер | Модель | Настройка в `config.yaml` |
   |---|---|---|
   | ПК с видеокартой NVIDIA 8 ГБ+ | `qwen3:8b` | `model: qwen3:8b` |
   | Ноутбук без видеокарты (только процессор) | `qwen3:4b-instruct` | `model: qwen3:4b-instruct`, `think: false` |

   Проверить, на чём работает модель: `ollama ps` → колонка PROCESSOR (`100% GPU` — отлично, `100% CPU` — бери instruct-модель).
3. **Claude Code** (по желанию, для сложных задач):
   ```
   irm https://claude.ai/install.ps1 | iex
   claude      # один раз войти в аккаунт
   ```
4. Клонировать и запустить:
   ```
   git clone https://github.com/<твой-ник>/capri.git
   cd capri
   run_capri.bat
   ```
   При первом запуске создастся `.venv` и `config.yaml`.

Запуск вручную: `python -m capri`. **Самопроверка** всех частей (Ollama и видеокарта, Claude, озвучка, Whisper,
«Привет, Капри», микрофон, системные команды, анимации): `selftest.bat` → отчёт в `data/selftest.txt`. Тесты: `pip install pytest && pytest`.

## Управление

- **ЛКМ по аватару** — открыть/закрыть чат, **перетаскивание** — переместить, **ПКМ** — меню.
- **Меню** (ПКМ по Капри или по значку в трее) — одно и то же, на русском или английском (🌐 Язык / Language):
  Позвать Капри · Написать команду… · Сказать голосом · Замолчать · Проверить ПК · Микрофон ·
  Слушать «Привет, Капри» · Озвучивать ответы · Гулять по экрану · Спрятать · Выход.
  Выбор запоминается в `data/state.json`.
- `/claude <задача>` — сразу отправить задачу Claude.
- Статусы: `ONLINE` · `THINKING` (локальная модель) · `CLAUDE` · `TALKING` · `ERROR`.

## Голос 🎤

- **Распознавание** — [faster-whisper](https://github.com/SYSTRAN/faster-whisper), локально, сам определяет язык (RU/DE/EN/HE).
- **Озвучка** — два движка (`voice.tts_engine` в `config.yaml`):
  - `edge` (по умолчанию) — живые нейроголоса Microsoft через [edge-tts](https://github.com/rany2/edge-tts), RU/DE/EN/HE. Нужен интернет, текст ответа уходит в Microsoft.
  - `piper` — [Piper](https://github.com/OHF-Voice/piper1-gpl), полностью офлайн, звучит проще. Используется и как запасной вариант без интернета.
- **«Привет, Капри»** — скажи фразу, и она начнёт слушать команду, а когда договоришь — остановится сама.
  Фразу ловит [vosk](https://alphacephei.com/vosk/) офлайн (русская модель ~45 МБ, `run_capri.bat` скачает её сам).
  Понимает и «эй / окей Капри», «hey Capri». Выключить — в меню.
- Управление: кнопка 🎤 в чате, горячая клавиша `Ctrl+Space` или ПКМ по аватару → «🎤 Сказать голосом».
- Нажал → говоришь → нажал ещё раз. Если Капри говорит, а ты начал говорить — она замолкает.
- Модели (~500 МБ) скачиваются один раз в `data/models/`.

Голосовой модуль ставится автоматически при запуске `run_capri.bat`. Вручную:
`.venv\Scripts\python -m pip install -r requirements-voice.txt`

## Мгновенные команды (без нейросети)

Работают сразу, голосом или текстом, на русском / Deutsch / English:

| Сказать | Что будет |
|---|---|
| пауза · продолжи · следующий трек · предыдущий трек | управляет тем, что играет (YouTube в браузере, Spotify, плееры) |
| что играет? | назовёт трек |
| поставь на 3:14 · перемотай на 30 секунд вперёд · отмотай на минуту · начни сначала | перемотка |
| громкость 40 · громче · тише на 20 · выключи звук · какая громкость | звук |
| яркость 70 · ярче · темнее | яркость (ноутбук или монитор с DDC/CI) |
| проверь компьютер · что грузит компьютер | диагностика: CPU, память, диски, ошибки в журналах, автозагрузка — отчёт в блокноте |
| нажми контрол шифт эскейп · нажми вин таб · нажми пробел три раза | нажимает клавиши |
| сделай скриншот | сохраняет в «Изображения\Capri» |
| заблокируй компьютер | блокировка экрана |
| открой дискорд · открой ютуб мюзик · открой пакет трейсер | программа с компьютера (из меню «Пуск»), если есть; иначе сайт |
| открой ютуб · найди на ютубе lo-fi · открой гитхаб | сайты: встроенные + твои из `config.yaml → sites` |
| какая погода · погода завтра в Берлине · нужен ли зонт | отвечает словами (open-meteo.com), браузер не открывает |
| посмотри, что у меня за ошибка в PowerShell · что у меня на экране | снимок экрана → Claude смотрит и объясняет |
| открой браузер · загугли … · таймер на 5 минут · запиши … | как раньше |

Пакеты для этих команд (`requirements-system.txt`) `run_capri.bat` ставит сам.
Идеи и часть кода этих команд — из [kystt29/capricorn](https://github.com/kystt29/capricorn) (MIT).

## Кто отвечает

- **Мгновенно, без нейросети:** команды из таблицы выше.
- **Ollama (локально):** разговор и простые вопросы.
- **Claude:** сложное — «напиши скрипт…», «почему не работает…», «объясни подробно…», длинные тексты, вопросы
  про экран (скриншот уходит в Anthropic только когда ты сам просишь посмотреть). Или явно: `/claude …`.
- Журнал — `data/capri.log`: что она услышала, кому отправила, ошибки. Если окно «зависнет», в `data/hang.log`
  запишется, на чём.

## Характер и голос

- **😈 Характер** (в меню): мягкая · дерзкая (по умолчанию) · грубая. В грубом режиме она ворчит, язвит и подкалывает,
  но без мата и без настоящих оскорблений — и задачу всё равно делает. Действует и на ответы Claude.
- **🎛 Голос Капри…** (в меню): голос Edge для каждого языка (в списке есть и *Multilingual*-голоса — они читают
  по-русски другим тембром, можно вписать любой голос Edge), скорость, высота и фильтры —
  робот, цифра, эхо, двойник, рация, глитч — плюс пресеты «Киберпанк», «Голограмма», «Рация», «Глитч», «Демон».
  «▶ Прослушать» сразу говорит с текущими настройками; «Сохранить» запоминает их в `data/state.json`.

## Капри живёт на экране

- Гуляет по низу экрана, телепортируется (с глитчем) на верхние края окон и сидит на них.
- Окно двигается — она едет вместе с ним. Окно закрыли или свернули — падает вниз.
- Можно взять мышью и бросить на заголовок любого окна — сядет туда.
- Выключить прогулки: ПКМ по ней → «🚶 Гулять по экрану» или `avatar.wander: false`.

## Своя внешность и анимации

Положи GIF/PNG в `assets/custom/` (папка в git не попадает) — Капри подхватит их сама.
Какая анимация когда играет, определяется по слову в имени файла:

| Слово в имени | Когда | Пример |
|---|---|---|
| `idle` (или без ключевого слова) | стоит / ждёт | `idle.gif`, `pose2.gif` |
| `walk` | идёт | `walk.gif` |
| `sit` | сидит на окне | `sit.gif` |
| `think` | думает | `think.gif` |
| `talk` | говорит | `talk.gif` |
| `listen` | слушает | `listen.gif` |
| `teleport` | перемещается | `teleport.gif` |

Если какой-то анимации нет, используется `idle`. Несколько файлов `idle` чередуются.

**Папка с кадрами** тоже подходит: положи PNG `0001.png, 0002.png, …` (минимум 3) в подпапку —
это одна анимация, а её тип берётся из имени папки (`walk/`, `talk/`, `think/` …; без ключевого слова — `idle`).
Скорость — `avatar.fps` (по умолчанию 12 кадров в секунду).
Анимации показываются и на рабочем столе, и на экране в окне «Personal Link».

## Языки

Быстрые команды понимают русский, немецкий и английский («открой браузер», «öffne Rechner», «set a timer for 5 min»).
Всё остальное понимает модель `qwen3:8b` — она отвечает на языке вопроса, включая иврит.
