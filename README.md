# Dolmetsch

Перевод субтитров онлайн-встреч с немецкого на русский поверх экрана. Только Windows 11.

Программа сама речь не распознаёт. Она читает готовые субтитры (Teams или Windows), переводит их
и показывает перевод в небольшом окне поверх остальных.

## Запуск

1. Распакуй архив в любую папку.
2. Запусти `Dolmetsch.exe`. Рядом с часами появится значок с буквой D, внизу экрана — окно перевода.
3. В звонке Teams включи субтитры: «…» → «Sprache und Sprachausgabe» → «Liveuntertitel anzeigen».

Если субтитров Teams нет (или встреча в Zoom, Meet, браузере), программа спросит:
«Включить субтитры Windows?» Ответ «Да» запускает субтитры Windows 11. В них один раз нужно выбрать
язык распознавания Deutsch.

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Старт / стоп перевода | Win+Alt+J |
| Показать / спрятать окно | Win+Alt+I |
| Профиль «Урок» ↔ «Важное» | Win+Alt+Y |

Сочетания меняются в `config.json` (меню значка → «Папка настроек и журнала»).

## Профили

- **Урок** — только офлайн-перевод. Текст никуда не отправляется. В будни с 9 до 17 включён сам.
- **Важное** — перевод через DeepL (точнее), при сбое офлайн. Нужен ключ DeepL: меню значка → «Ключ DeepL…».
  Бесплатного тарифа DeepL хватает примерно на 10–15 часов речи в месяц.

## Окно

- Перетаскивается мышью, размер меняется за правый нижний угол.
- Правая кнопка мыши по окну или по значку — меню.
- Серым курсивом — немецкая фраза, которая ещё дописывается. Перевод появляется, когда предложение закончено.
- По умолчанию окно не видно собеседникам при демонстрации экрана (меню → «Не показывать окно…»).

## Текст встречи

Каждая встреча пишется в файл `транскрипт.md` (немецкий и перевод):

- если есть папка Capri — `Документы\Capri\Уроки\ДАТА ВРЕМЯ — Тема\`;
- иначе — `Документы\Dolmetsch\`.

## Если что-то не работает

- Меню → «Сохранить отчёт для разбора». В «Документах» появится архив `Dolmetsch-отчёт-….zip`:
  журнал, настройки и структура окон Teams. Текста встреч и имён в нём нет.
- Журнал: `%APPDATA%\Dolmetsch\dolmetsch.log`.
- Проверка скорости перевода: `Dolmetsch.exe --bench --out bench.txt`.
- Проверка чтения субтитров без окна: `Dolmetsch.exe --probe 30 --out probe.txt` (во время звонка).

## Как устроено

```
dolmetsch/
  capture/     источники субтитров: Teams, субтитры Windows, выбор между ними
  translate/   переводчики: офлайн (Opus-MT), DeepL, выбор по профилю
  pipeline.py  очередь: событие → перевод → окно и файл
  transcript.py  текст встречи
  ui/          окно, уведомление «Да / Нет»
  hotkeys.py   горячие клавиши
  app.py       связь всех частей, значок в трее, служебные режимы
```

Правила поиска панели субтитров Teams лежат в `dolmetsch/capture/teams.py` (словарь `PROFILE`).
Если Microsoft поменяет вёрстку, правится только он.

## Разработка

```
pip install -r requirements.txt pytest
python -m pytest
python -m dolmetsch
```

Офлайн-модель: `Helsinki-NLP/opus-mt-tc-big-de-zle` (CC-BY-4.0), формат CTranslate2 int8,
папка `models/opus-mt-de-ru`. Сборка для Windows делается в GitHub Actions.
